## Language Switcher adaptation

Adapter: Vitalik Makhnev, Language Switcher project.

Language Switcher selects the included language lists, normalizes Unicode and
spelling variants used for lookup, removes invalid and noisy entries, filters
single-character entries using language-specific rules, merges duplicates, and
stores the result in normalized frequency-rank order.
